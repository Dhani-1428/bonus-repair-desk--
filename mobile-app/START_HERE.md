# 🚀 START HERE - Get Your App Running!

## ✅ Step 1: API URL Updated!
I've already updated your API URL to use your computer's IP: `172.20.10.6`

## 📱 Step 2: Start Expo Server

Open a terminal in the `mobile-app` folder and run:
```bash
npm start
```

**You will see:**
- A QR code in the terminal
- Text saying "Metro waiting on..."
- Options to press `i` for iOS or `a` for Android

## 📲 Step 3: Install Expo Go on Your Phone

**iPhone:**
- Open App Store
- Search "Expo Go"
- Install (it's free)

**Android:**
- Open Google Play
- Search "Expo Go"  
- Install (it's free)

## 📷 Step 4: Scan the QR Code

**On iPhone:**
1. Open the **Camera app** (regular camera, not Expo Go)
2. Point it at the QR code in your terminal
3. A notification will appear - tap it
4. App opens in Expo Go automatically!

**On Android:**
1. Open the **Expo Go app**
2. Tap "Scan QR code" button
3. Point camera at QR code in terminal
4. App loads automatically!

## ⚠️ Important Notes:

1. **Same WiFi Required:** Your phone and computer must be on the same WiFi network

2. **Website Must Be Running:** In another terminal, make sure your website is running:
   ```bash
   cd ..
   npm run dev
   ```

3. **If It Doesn't Work:**
   - Make sure both devices are on same WiFi
   - Check that website server is running
   - Try restarting Expo: Press `Ctrl+C` then `npm start` again

## 🎉 That's It!

Once you scan the QR code, the app will load on your phone and you can start using it!
